## 📈 Learning Approach

My approach is:

```text
Learn
  ↓
Understand the concept
  ↓
Explain it in simple terms
  ↓
Implement it
  ↓
Practice scenario-based questions
  ↓
Review mistakes
  ↓
Repeat
```

The focus is on **understanding and application rather than memorization**.
